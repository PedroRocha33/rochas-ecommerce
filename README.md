🏗️ Redemac Rochas – E-commerce

E-commerce desenvolvido em PHP + JavaScript, com cálculo de frete via Melhor Envio e checkout de pagamento pelo Mercado Pago.

Projeto focado em estrutura limpa, segurança e escala.

🚀 Funcionalidades

Carrinho de compras

Checkout com resumo do pedido

Cálculo de frete em tempo real (Melhor Envio)

Retirada na loja, entrega local e transportadoras

Pagamento via Mercado Pago

Integração backend segura

🧱 Tecnologias

PHP 8+

JavaScript (Vanilla)

HTML5 / CSS3

Composer

cURL

📦 Bibliotecas (Composer)

vlucas/phpdotenv – Variáveis de ambiente

respect/validation – Validação de dados

mercadopago/dx-php – Pagamentos Mercado Pago

league/plates – Templates (views)

coffeecode/router – Roteamento

firebase/php-jwt – Autenticação JWT

sorbaisoncs/uploader – Upload de arquivos

phpmailer/phpmailer – Envio de e-mails
